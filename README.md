# 组合模拟盘：C_top50 主仓 + FB_dip 机会仓

从 [Bowen389/duogumoni](https://github.com/Bowen389/duogumoni)（retail_alpha 研究仓库）里只取出这一个组合需要的代码和模型，
用一个 **10 万元**模拟账户，由 GitHub Actions 在每个交易日**北京时间 17:00** 自动成交、记账、生成下一交易日清单。

👉 **每日净值和操作清单：[`paper/README.md`](paper/README.md)**

> ⚠ 10 万元对 C_top50 偏小：主仓 7 万分成 50 份，每只约 1,300 元，股价高于约 13 元的股票连一手都买不起，只能用替补的低价股，
> 主仓会有约 20% 现金闲置（测试 9/15–9/29：主仓 6.9 万中约 1.4 万是现金）。这是账户规模的问题，不是程序错误；
> 想更贴近回测可以把 `PAPER_CASH` 调大（例如 100 万），或者把机会仓比例调到 50%，让现金更多地由 FB_dip 使用。

## 组合规则（strategies2/README.md 第 11 节）

| 仓位 | 资金 | 规则 | 成交 |
|---|---|---|---|
| 主仓 **C_top50** | 70% | 三个 LightGBM 模型（16 个散户短期因子 / +12 个长期犯错因子 / +股东户数因子）行业中性后排名平均；中证1000 内持 50 只等权，每天最多换 2 只；R3：超额回撤超过 8% 时一半仓位换成中证1000ETF，回到 4% 以内恢复 | 下一交易日收盘价（尾盘集合竞价）；涨停/停牌买不进用替补，跌停/停牌卖不出继续持有 |
| 机会仓 **FB_dip** | 30% | 低位首板（首板前收盘低于 60 日中位数、10cm、不是开盘即涨停）；前一日中证1000 在 20 日线下、全市场跌停占比 < 3% | 次日开盘低开 2%–7% 才买，低开深的优先，最多 2 只、每只半个机会仓；买入后下一个交易日收盘卖出（跌停/停牌顺延） |

- 两仓分开记账，各自用自己的持仓和现金调用策略自带的 `signal` 工具；每天收盘后**只用现金**把两仓调回 70/30，不强制卖股票。
- 研究结果（主仓扣千1滑点）：机会仓 30% 时，样本外 2020–22 年化 22.5% / 回撤 −21.1%，研究期 2023–26 年化 16.6% / 回撤 −23.9%；只做 C_top50 时回撤约 −30% 到 −34%。
- 费用：主仓买万5、卖千1，每笔最低 5 元；机会仓佣金万2.5、印花税万5、单边滑点千1。
- 初始资金 `PAPER_CASH` 和机会仓比例 `PAPER_FB_RATIO` 在 `.github/workflows/paper.yml` 的 `env` 里，只对新建的账户生效（改完删掉 `paper/accounts`、`paper/signals` 再手动运行一次）。

## 每天做什么（`paper/run_daily.sh`）

1. 下载 [chenditc/investment_data](https://github.com/chenditc/investment_data) 的 Qlib 日线数据（约 540MB）
2. 行业分类（baostock）、面板、散户因子、长期犯错因子、股东户数增量（东方财富）和因子
3. 全市场跌停占比（`paper/market.py`，FB_dip 的市场条件）
4. `paper/sim.py run`：对每个未处理的交易日依次 成交 → 盯市 → 再平衡 → 出清单，结果提交回仓库

数据源每天发布的时间不固定（北京时间 16:17 到次日 03:49 都出现过），17:00 时如果当天数据还没发布，这次不处理当天，
之后的运行会按当天真实价格补上。所以 workflow 另有 21:00 和次日 08:30 两次补跑，账户已是最新时十几秒就结束；不需要可以删掉那两行 cron。

本地运行（Python 3.11）：`pip install -r paper/requirements.txt && bash paper/run_daily.sh`

## 需要知道的

- **10 万元对 C_top50 偏小**：主仓 7 万分到 50 只，每只约 1,300–2,000 元，股价高于约 13–20 元的股票买不起一手，清单会标“资金不足一手，用替补”，持仓会偏向低价股，也会有一部分现金闲置。和 100 万口径的回测会有差距。
- 中证1000ETF 没有单独的价格数据，用中证1000 指数日收益近似。
- 除权除息用复权因子把股数折算（相当于分红再投资）；复权因子变化小于 0.3% 的小额分红忽略。
- 模拟盘按开盘价/收盘价成交，没有计入冲击成本和排队成交失败，实盘会更差。
- 仅供学习研究，不构成投资建议。
