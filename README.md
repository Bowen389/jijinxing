# 进攻版 S_top3 模拟盘（情绪周期 + 大涨/大跌概率）

[Bowen389/duogumoni](https://github.com/Bowen389/duogumoni)（retail_alpha 研究仓库）strategies2/README.md 第 7 节“进攻版（方案 A）”的实盘化：
训练生产模型、每日清单工具，加一个 **10 万元**模拟账户，由 GitHub Actions 在每个交易日**北京时间 17:00** 自动成交、记账、出下一交易日清单。

👉 **每日净值、持仓和操作清单：[`paper/README.md`](paper/README.md)**

## 规则（研究结论里的“可用配置”）

| 项目 | 规则 |
|---|---|
| 股票池 | 中证1000（按历史成分） |
| 打分 | 排名平均：①“不对称”打分 = 大涨概率 − 大跌概率；② K_top3 的六个 5 日模型原始打分 |
| 持仓 | 最多 3 只，等权（每只约 1/3 资金） |
| 卖出 | 持仓排名跌出前 60，或已调出中证1000；开盘一字跌停/停牌卖不出则继续持有 |
| 买入 | 空位按排名补足；开盘一字涨停/停牌/资金不足一手时按顺序用替补 |
| 择时 | 不择时（研究中没有一条情绪择时规则在各区间都稳定有效） |
| 成交 | T 日收盘后出清单，T+1 开盘集合竞价成交；买万5、卖千1（含印花税）、每笔最低 5 元、单边滑点千1 |

**两个“大波动”模型**（`senti/model.py`，LightGBM 二分类）：目标是 T+1 开盘买入到 T+3 收盘涨 ≥10% / 跌 ≥10%。
特征共 75 个：散户因子 16 + 长期犯错因子 12 + 个股短线特征 14（连板、炸板、10 日涨停次数、振幅、收盘位置、隔夜跳空、量比……）
+ 市场情绪 33（涨停/跌停占比、炸板率、最高连板、接力赚钱效应、涨跌家数、成交额，及其 5 日均值和 120 日 z 分数）。
训练 2015-01 ~ 2024-08，早停验证 2024-09 ~ 2026-09（与六个 5 日模型相同）；验证 AUC：大涨 0.731、大跌 0.783。

## 预期（请按研究结果看，不要按下面的验证期）

研究中的结果（千1 滑点，不同参数的合理区域）：

| 区间 | 年化 | 最大回撤 |
|---|---|---|
| 研究期 2023–26 | 24.9% | −45% |
| 样本外 2020–22 | 35.4% | −41% |
| **最近一年 2025-09 ~ 2026-09（模型完全没见过）** | **16.5%** | **−37%** |

分年收益：2020 +0%，2021 +156%，2022 −4%，2023 −2%，2024 +17%，2025 +94%。收益高度集中在少数年份，**多数年份平淡甚至亏损，回撤 −40% 左右是常态**。日换手 10–16%，对成本敏感。

用本仓库的生产模型重跑 2024-09 ~ 2026-09：总收益 +138%（中证1000 +68%），最大回撤 −32.5%；同一段只用 5 日模型 +12%，只用不对称打分 +141% 但回撤 −43%。
这段时间是模型的早停验证期（用来选树的棵数），结果偏乐观，只用来确认程序接线正确。

## 每天做什么（`paper/run_daily.sh`）

1. 下载 [chenditc/investment_data](https://github.com/chenditc/investment_data) 的 Qlib 日线数据（约 540MB）
2. 行业分类（baostock）、面板、散户因子、长期犯错因子、股东户数增量（东方财富）和因子
3. 市场情绪指标 + 个股短线特征（`senti/features.py`，与研究代码逐项一致，已核对 3000 天×52 列完全相同）
4. `paper/sim.py run`：对每个未处理的交易日依次 开盘成交 → 收盘盯市 → 用账户的真实持仓出下一日清单，结果提交回仓库

数据源每天发布时间不固定（北京时间 16:17 到次日 03:49 都出现过）。17:00 数据还没出时，这次不处理当天，之后的运行会按当天真实价格补上；
所以 workflow 另有 21:00 和次日 08:30 两次补跑，账户已是最新时十几秒就结束。不需要可以删掉那两行 cron。

## 文件

| 路径 | 内容 |
|---|---|
| `paper/README.md` | 净值、持仓、下一交易日清单（自动更新） |
| `paper/accounts/S_top3/` | nav.csv（每日净值）、trades.csv（成交）、positions.csv（持仓）、state.json |

| `paper/sim.py`、`paper/run_daily.sh` | 模拟盘程序、每日流程 |
| `models/` | senti_up / senti_dn（本仓库训练）+ K_top3 的六个 5 日模型（来自原仓库） |

本地运行（Python 3.11）：`pip install -r paper/requirements.txt && bash paper/run_daily.sh`

## 需要知道的

- 持 3 只的集中策略，单只股票的涨跌停就能让账户一天波动 5–10%。这是“进攻版”，不适合当主仓。
- 10 万元分 3 份，每份约 3.3 万，股价高于约 330 元（科创板约 165 元）买不起一手时用替补。
- 模型建议每年重训一次：`python senti/model.py train`（大涨/大跌）；5 日模型用原仓库的 `strategies2/live.py train --strategy K_top3`。
- 模拟盘按开盘价成交，没有计入冲击成本和集合竞价排队不成交，实盘会更差。
- 仅供学习研究，不构成投资建议。
